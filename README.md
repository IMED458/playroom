# Play Room Arena — მართვისა და POS სისტემა

გეიმინგ-კლუბის სრული მართვის სისტემა: სათამაშო სესიები, ჯავშნები, სალარო,
ფასდაკლებები/ვაუჩერები, ტურნირები, პერსონალის ანაზღაურება და ანალიტიკა.

## გაშვება

```bash
npm install
npm run dev
```

სისტემა გაიხსნება `http://localhost:3000`-ზე.

საწყისი მომხმარებელი: `admin` / `AdminPlayRoom2026!`
(პაროლი შეიცვლება `.env`-ში `ADMIN_INITIAL_PASSWORD`-ით პირველ გაშვებამდე).

## პროდაქშენ ბილდი

```bash
npm run build
npm start
```

## მონაცემთა ბაზა

ბაზა ლოკალურია — SQLite ფაილი `data/playroom.sqlite`.
ის ავტომატურად იქმნება პირველი გაშვებისას და git-ში არ ინახება.
საჭიროების შემთხვევაში მიგრაცია Firebase-ზე შესაძლებელია მოგვიანებით —
ყველა მონაცემთან წვდომა თავმოყრილია `server/routes/` და `server/db.ts`-ში.

### სარეზერვო ასლი
`data/playroom.sqlite` ფაილის კოპირება საკმარისია.

## ძირითადი შესაძლებლობები

- **სესიები** — ფიქსირებული ხანგრძლივობა ან **„მიმდინარე"** (ღია) სესია,
  რომლის თანხაც რეალურად ნათამაშები დროით გამოითვლება დასრულებისას.
- **თამაშის შეწყვეტა** — თუ მოთამაშემ არ გადაიხადა: სესია სრულდება,
  მოწყობილობა თავისუფლდება, თანხა ჩამოიწერება ან რჩება დავალიანებად.
- **მოწყობილობები** — დაჯგუფებული ზონებად (PC / PlayStation / საჭე);
  დროგასულები ავტომატურად ამოდის სიის თავში.
- **პერსონალი** — საათობრივი ხელფასის ნაცვლად დღის შემოსავლის პროცენტი.
  პროცენტი განისაზღვრება თითოეულ თანამშრომელზე; დღის ბოლოს ხდება
  განაწილების დაფიქსირება და გაცემა, რაც სალაროდან აკლდება დღის დახურვისას.
- **ტურნირები** — საჯარო სარეგისტრაციო ბმული (`/?tournamentReg=<id>`);
  რეგისტრაციები ჩანს როგორც ადმინთან, ისე ოპერატორთან.
- **ანალიტიკა** — დღიური დინამიკა, პიკური საათები, ზონების წილი და
  მოწყობილობების რეიტინგი.
- **ადმინის უფლებები** — ყველა ჩანაწერის (სესია, ტრანზაქცია, ჯავშანი,
  მოწყობილობა, თანამშრომელი, ვაუჩერი, ტურნირი, დღის დახურვა) რედაქტირება და წაშლა.

## პარამეტრები

`.env` ფაილი (იხ. `.env.example`):

- `AUTH_SECRET` — ტოკენების ხელმოწერის გასაღები (პროდაქშენში აუცილებლად შეცვალეთ)
- `ADMIN_INITIAL_PASSWORD` — საწყისი ადმინის პაროლი
- `TZ` — დროის სარტყელი
- `PORT` — სერვერის პორტი (ნაგულისხმევი 3000)
