# Play Room Arena — მართვისა და POS სისტემა

გეიმინგ-კლუბის სრული მართვის სისტემა: სათამაშო სესიები, ჯავშნები, სალარო,
ფასდაკლებები/ვაუჩერები, ტურნირები, პერსონალის ანაზღაურება და ანალიტიკა.

**სისტემა მთლიანად ბრაუზერში მუშაობს — სერვერი არ სჭირდება.**
მონაცემთა ბაზა არის ნამდვილი SQLite (sql.js), რომელიც ინახება ბრაუზერის
IndexedDB-ში. სწორედ ამიტომ შესაძლებელია GitHub Pages-ზე დაჰოსტვა.

🔗 **https://imed458.github.io/playroom/**

საწყისი მომხმარებელი: `admin` / `AdminPlayRoom2026!`

## ლოკალური გაშვება

```bash
npm install
npm run dev
```

## ბილდი და გამოქვეყნება

```bash
npm run build       # ბილდი ხვდება docs/ საქაღალდეში
git add -A && git commit -m "deploy" && git push
```

GitHub Pages პარამეტრი: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, Folder: `/docs`**.

## ⚠️ მნიშვნელოვანი: სად ინახება მონაცემები

მონაცემები ინახება **იმ ბრაუზერში, სადაც სისტემას იყენებთ** — არა სერვერზე.
ეს ნიშნავს:

- თითოეულ კომპიუტერს/ბრაუზერს აქვს თავისი ბაზა; ისინი ავტომატურად არ სინქრონდება.
- ბრაუზერის მონაცემების გასუფთავება წაშლის ბაზას.
- გადატანა და დაზღვევა ხდება **სარეზერვო ფაილით**:
  პარამეტრები → ტარიფები & ფასები → „ასლის გადმოწერა" / „ასლიდან აღდგენა".

რეკომენდაცია: სამუშაო დღის ბოლოს გადმოწერეთ ასლი.
როცა დაგჭირდებათ რამდენიმე მოწყობილობიდან ერთდროული მუშაობა და
ავტომატური სინქრონიზაცია — მონაცემთა შრე გადადის Firebase-ზე
(კოდის მხოლოდ `src/core/` ნაწილი იცვლება, ინტერფეისი უცვლელი რჩება).

ავტორიზაცია ასევე კლიენტის მხარესაა — ის მოდულებზე წვდომას არეგულირებს,
მაგრამ არ იცავს მონაცემებს იმ ადამიანისგან, ვისაც ამ კომპიუტერთან წვდომა აქვს.

## ძირითადი შესაძლებლობები

- **სესიები** — ფიქსირებული ხანგრძლივობა ან **„მიმდინარე"** (ღია) სესია,
  რომლის თანხაც რეალურად ნათამაშები დროით გამოითვლება დასრულებისას.
- **თამაშის შეწყვეტა** — თუ მოთამაშემ არ გადაიხადა: სესია სრულდება,
  მოწყობილობა თავისუფლდება, თანხა ჩამოიწერება ან რჩება დავალიანებად.
- **მოწყობილობები** — დაჯგუფებული ზონებად (PC / PlayStation / საჭე);
  დროგასულები ავტომატურად ამოდის სიის თავში.
- **პერსონალი** — საათობრივი ხელფასის ნაცვლად დღის შემოსავლის პროცენტი.
- **ტურნირები** — საჯარო სარეგისტრაციო ბმული; რეგისტრაციები ჩანს
  ადმინთანაც და ოპერატორთანაც.
- **ანალიტიკა** — დღიური დინამიკა, პიკური საათები, ზონების წილი, რეიტინგი.
- **ადმინის უფლებები** — ყველა ჩანაწერის რედაქტირება და წაშლა.
